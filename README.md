# Projeto de Lista de Livros

Projeto desenvolvido na disciplina de Programação - Web Coding.

## Estrutura do projeto

### API - Python e Flask
API responsável por disponibilizar uma lista de livros em formato JSON.

### Frontend - React
Interface desenvolvida com React para consumir a API e exibir os livros.

## Tecnologias utilizadas

- Python
- Flask
- JavaScript
- React
- Vite
- HTML
- CSS

## Como executar

### 1. Executar a API

Entre na pasta:

`api-livros-flask`

Instale as dependências:

`pip install -r requirements.txt`

Execute:

`python app.py`

A API estará disponível em:

`http://127.0.0.1:5000/livros`

### 2. Executar o Frontend

Entre na pasta:

`frontend-livros`

Instale as dependências:

`npm install`

Execute:

`npm run dev`

## Objetivo

Desenvolver uma aplicação web que utiliza uma API Flask para fornecer dados de livros e uma interface React para apresentá-los.
